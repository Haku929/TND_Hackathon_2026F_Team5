## 2. 新しく足した部分のレビュー

- **DB の変更（移行 SQL）:** 列と索引を足すだけ。既存のデータは変わらない。何度実行しても同じ結果になる。
- **投入ツール（`data/load_university.py`）:**
  - SQL はすべてパラメータ化。大学の名前（slug）は、英小文字と数字だけを受け付け、`ritsumei` は拒否する。
  - その大学の分だけを入れ替える。1 回のトランザクションで、入れた後の件数が入力と合わなければ、全部もとに戻る。他の大学・分野・用語には触れない。
  - エラーの表示は、種類だけ（接続文字列を出さない）。入力の検証（ID の印、384 次元、正規化、重複、対応する先生と分野）に、16 件のテストがある。
- **データ取得（KAKEN の API）:** 1 秒に 1 回以内の間隔を守る。キーは、環境変数か `.env`（Git の対象外）だけから読む。
- **パッケージの取得:** データ準備用の Python ライブラリは、証明書の検証を無効にせず、OS の証明書ストアを使って取得した（`truststore`）。バージョンは固定していない（データ準備の端末の中だけで使う）。
