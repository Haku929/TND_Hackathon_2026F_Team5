# KAKENの分類と30分野の対応表（#22）

## 入力と対応表

入力は #21 の `researchers.json`（現在所属が立命館大学の1,201人、重複除去後3,374課題）です。分野は #6 の当初一覧を見直し、チームが了承した30分野を使用します。日本語名と英字IDの一覧は `fields_catalog.json` にあります。「その他」は追加していません。

当初一覧から、地域別の文学・歴史、考古と文化遺産、芸術・映像・デザイン、AIとデータサイエンスを統合しました。生命科学は生物・生命、薬学・創薬、医学・健康に分割し、電気電子をロボティクスに追加しました。地域研究、数学・数理、物理・天文・地球、化学・材料・ナノ、建築・土木・防災を追加して30分野を維持しています。GitHubの #6 本文にも、同じ30分野の名前とIDを反映しています。

KAKENには新しい審査区分と旧来の研究分野が混在しています。[日本学術振興会の審査区分表・旧分類表への案内](https://www.jsps.go.jp/j-grantsinaid/02_koubo/shinsakubun.html)と、取得済みデータに実際に含まれる分類名を照合しました。`field_map.csv` はチーム用の対応表であり、KAKEN公式の30分野分類ではありません。

CSVの列は次のとおりです。

| 列 | 内容 |
| --- | --- |
| `source_kind` | 審査区分 `review_section`／旧研究分野 `research_field` |
| `table_type` | APIの分類表の種類 |
| `nii_code` | API内部コード。表示上の小区分番号とは別の文字列 |
| `path` | 旧分類の階層パス。先頭の0も保持 |
| `source_name` | APIの分類名 |
| `field_id` | 30分野のID。未分類は空欄 |
| `note` | 対応根拠、または未分類の理由 |

先頭5列すべてを照合キーにします。コードの衝突や、コードが空欄の「人文地理学」を区別するためです。複数分野に対応する場合は同じ照合キーを複数行に記載します。「国文学」「中国語・中国文学」は地域を限定しない文学に対応しますが、「天文学」「人文学」は文字列に文学を含むだけなので対応させません。「文化学」を化学に、「植物栄養学」をスポーツ科学にするなど、不適切な部分一致も除外しました。CSVの対応理由はレポートにも保持し、同じ分類キーに異なる理由がある場合は重複を除いて併記します。

## 分野の付け方

1. 課題に審査区分があれば、小区分→中区分→大区分の順に、存在する最も細かい階層だけを使います。合同審査区分は一つの分類として扱います。
2. 審査区分がなければ旧研究分野を使い、同一課題・同一分類表で子の分類がある親の分類を除きます。
3. 残った分類をCSVで照合し、その研究者の全参画課題について分野IDを重複除去してまとめます。

これは参画課題の分類を研究者に付ける処理です。研究者自身の専門を個別に確認した結果ではありません。細かい区分が未分類でも、分類率を上げるために広い親区分へ戻すことはしません。実行時の推論・文章のキーワード検索・LLM呼び出しはありません。

## 見直した分野の対応範囲

| 分野 | 主な審査区分・対応方針 |
| --- | --- |
| 文学 | 小区分02010〜02050。旧分類の日本・中国・英語圏・欧州の文学、文学一般を含む |
| 歴史学 | 小区分03010〜03040。日本史・アジア史・アフリカ史・欧米史・史学一般を含む |
| 地域研究 | 小区分80010、旧分類の地域研究 |
| 数学・数理科学 | 中区分11・12に属する小区分と、旧分類の代数・幾何・解析・数学一般 |
| 電気電子・ロボティクス | 従来のロボティクスに中区分21の電気電子系を追加 |
| 化学・材料・ナノ科学 | 中区分26〜28と32〜37を中心に、材料・化学工学・ナノ・化学を対応付け |
| 建築・土木・防災学 | 中区分22・23、小区分25030、旧分類の建築・土木・地盤・水工・防災等 |
| 生物学・生命科学 | 明確な生物・生化学・神経系。中区分43〜46・51等を中心に対応付け |
| 薬学・創薬科学 | 中区分47と旧薬学系 |
| 医学・健康科学 | 中区分48〜50・52〜58・90等の基礎医学・臨床医学・看護・医工学、旧分類の一般健康科学 |

この表は対応範囲の概要です。実際に使うキーと分野IDはCSVで確認できます。化学系の生命研究など、複数分野への対応を許容します。一般の健康科学・公衆衛生は医学・健康科学、スポーツ・体育・身体運動・リハビリはスポーツ科学を基本とし、小区分59040（栄養学および健康科学関連）は両方に対応させています。「生物系」「医歯薬学」だけでは生命系3分野の分割先を決めず、臨床心理学は名称だけで医学に追加しません。

## 検証結果

| 項目 | 件数 |
| --- | ---: |
| 研究者 | 1,201人 |
| 1分野以上付いた研究者 | 1,157人（96.3%） |
| 未分類の研究者 | 44人 |
| 研究者と分野の組 | 1,706件 |
| 入力に含まれる分類キー | 842件 |
| CSVの行数（ヘッダー除く） | 921行 |
| 階層の選択後に使った分類キー | 710件 |
| うち対応あり／未分類 | 627件／83件 |
| 対応表に行そのものがないキー | 0件 |

当初の30分野で未分類だった206人から44人へ減りました。未分類者全員に分類情報はありますが、文化人類学・農学・一般の機械工学などの対応先がない場合や、複数分野をまとめた広い分類で専門を限定できない場合は残しています。未分類者のうち「文化人類学および民俗学関連」を持つ人は5人、「文学、言語学およびその関連分野」という広い分類を持つ人は5人でした（重複あり）。全員のID・氏名・分類キーと、区分ごとの理由は自動生成のレポートに保存しています。

30分野すべてに1人以上が付いています。生命系3分野の重複除去後の人数は121人です。旧生命科学109人の単純な分割ではなく、全課題分類を見直して旧分野外の16人にも付きました。旧生命科学の4人は広い分類等で分割先を限定できませんが、他の分野は保持しています。

行の欠落は0件ですが、全対応の人によるレビューは未実施です。96.3%は分野が付いた研究者の割合であり、分類の正解率ではありません。未分類者も元の `researchers.json` に保持しています。Issueへの結果コメントと、PR・mainへの反映は別途必要です。

分野付け8件・取得処理8件の計16テストで、完全一致の照合、階層選択、複数分野、未分類、対応理由の保持、「文化学」を化学にしないこと等を検証しました。16テスト、`npm run lint`、`npm run format:check` はすべて成功しています。実データでは、全分類キーの収録、研究者ID・分野IDの参照整合性、組の重複がないこと、同じ入力で同じ結果になること、入力ファイルが変わらないことを確認しています。

## 再生成と確認

手順は [README](README.md#研究者の分野付け22) を参照してください。対応を直す場合はCSVの該当キーと分野ID・理由を更新して再実行します。詳細レポートにある `unused_mapping_keys` は、主に階層選択で除いた親分類であり、対応表の行の欠落とは異なります。
